# 默认生成提示词

## 人物外观

上传的主头像是人物面部外观的唯一依据。严格保留原图中可见的眉毛形状、眼睛大小与形状、眼距、内外眼角、鼻梁鼻翼、嘴唇轮廓、下巴、脸型、发际线、发色、妆容、面部肤色及年龄观感。保留原本的五官比例和辨识度，不重新设计长相，不借用其他人物的脸。不同视角表现为同一个人物自然转身后的外观。原图未展示的身体、侧面结构及背面发型进行保守、合理的设计补全，并在所有视图中保持一致。

## 九头身与长腿比例

以颅顶至下巴的距离为一个头高H，以赤足中立站姿的解剖身高为比例基准，颅顶至赤足脚底的总高度以严格约9H为目标；头发蓬松高度、鞋底厚度及高跟鞋造成的抬升均不计入9H，不借助鞋跟凑足九头身。

头部体积保持正常偏小，严禁大头、幼态头身比、头大身小、头肩比失调。从颅顶向下计算，赤足参考体的比例目标为：下巴约位于1H，肩线约位于1.3H，裆点约位于4H，膝关节约位于6.5H，脚底位于9H。头部宽度约为肩宽的45%—50%，肩宽约1.5—1.7H，颈部长度约0.3H。脸宽与头高比例自然，以参考图的脸型为准，不为了凑比例加宽脸型、放大头部或增加颅顶高度。

裆点至赤足脚底约5H，形成明显修长的双腿；大腿与小腿均匀修长，髋部、膝部和踝部衔接自然，保留合理的骨骼结构与肌肉体积。颈部长度、肩宽和躯干保持协调，不用拉长脖子、极端缩小头部、抬高裤腰或夸张透视代替长腿结构。

## 姿态与服装

三个全身视角均采用自然中立站姿，身体直立，肩部放松且同高，双腿伸直，双脚平行并略微分开，双臂自然垂于身体两侧，手部自然放松。保持相同姿态，仅改变人物朝向。正面和背面尽量清楚呈现双手；严格侧面允许远侧手臂、手和腿自然被近侧肢体遮挡，不为了露出远侧肢体扭转身体、张开手臂或改变站姿。

服装统一为白色背心式分体泳装：白色背心式泳衣上装搭配白色平口泳裤，并穿简洁高跟凉鞋。所有视角中的背心领口与肩带宽度、上装长度、裤腰高度与裤长、凉鞋鞋型与跟高、配饰、颜色与材质一致；不新增首饰。服装自然贴合身体结构，面料不透明，不用宽大衣物掩盖比例错误。不使用抬高裤腰、极高腿口或鞋跟抬升伪造长腿。高跟凉鞋的鞋底与鞋跟增高不计入九头身比例。

全身视图采用远距离长焦、接近正交的弱透视展示，统一摄影机高度与人物比例尺，相机保持水平，并与人物胸部或腰部同高，垂直线不倾斜，无广角变形。中性灰色无缝摄影棚背景，柔和均匀的灯光，统一曝光和白平衡。保留头像中的面部色调，皮肤细节自然，发丝和服装材质清晰，脚下保留轻微接触阴影。

禁止广角变形、俯拍、仰拍、近景透视夸张、蓬松发型增加头围、夸张颅顶、宽脸、幼态比例、头肩比失调、头大身小、不同视角头部大小变化。保持参考人物原有年龄观感和自然结构，采用中性造型展示。
