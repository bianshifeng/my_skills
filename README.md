## 头像转九头身角色设定图

技能名：`portrait-to-character-sheet`

### 使用

将完整的 [skills/portrait-to-character-sheet](skills/portrait-to-character-sheet) 文件夹安装到宿主的技能目录中，再选择该技能并上传一张清楚的头像。也可以明确输入：

> 使用 $portrait-to-character-sheet，根据我上传的头像直接生成角色设定图。

已选择技能并提供可用头像时，默认直接调用图像生成工具，不再要求确认，也不先返回提示词。若明确要求“只给提示词”，则只输出提示词。

### 默认输出

- 一张 16:9 横向写实角色设定图。
- 左侧 28%：正面头肩特写、45°侧面特写，上下排列。
- 右侧 72%：正面全身、向画面左侧的严格90°侧面全身、180°背面全身。
- 九头身长腿比例目标，三张全身使用同一比例尺。
- 白色背心式分体泳装、简洁高跟凉鞋、中性灰色摄影棚背景。
- 保留参考头像的五官、脸型、发型、妆容、肤色及年龄观感。

可追加“改成白色连体泳衣”“改成八头身”等要求，覆盖对应默认值。

### 运行要求

宿主需要提供支持参考图输入的图像生成工具。技能本身提供工作流与提示词，不包含图像模型或独立图像服务；只有文本能力的宿主不能仅靠安装此技能生成图片。

九头身、跨视角人物一致性和精确角度属于生成与检查目标，实际效果取决于所用模型。图像生成失败或受宿主安全规则限制时应如实说明，不能将提示词文本当作已完成图片。
